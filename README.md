# Mini Data Analysis – Gabe Ramón

This repo is my Mini Data Analysis project for Intro to Data Science. I'm using the Rolling Stone 500 Greatest Albums data set to look at how the 2003 and 2020 lists compare.

## Files

- `MiniDataAnalysis1.qmd` – my main assignment file with all the code and answers
- `Mini_Data_Analysis.Rproj` – the RStudio project file
- `.gitignore` – tells Git which files to skip
- `README.md` – this file

## How to use this repo

Clone the repo and open `Mini_Data_Analysis.Rproj` in RStudio. Put the data file in a folder called `dat` so the path is `dat/RollingStone500.csv`. Then open `MiniDataAnalysis1.qmd` and click Render to run everything.
